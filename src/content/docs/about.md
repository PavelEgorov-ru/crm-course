**CRM / изнутри** — рабочее название открытого проекта Павла Егорова о технической базе CRM-маркетолога.

Сначала — материалы для себя и коллег. Постепенно отдельные статьи и демонстрационные примеры можно будет собрать в последовательный курс. Содержание и порядок тем ещё обсуждаются.

## Свободный доступ

Читать материалы и пробовать примеры можно будет без регистрации. Проект развивается с добровольной поддержкой читателей.

## Поддержать проект

Ссылка для донатов появится здесь, когда будет выбран сервис. Доступ к материалам останется свободным.

Пока можно помочь обратной связью: [сообщить об ошибке или предложить улучшение](https://github.com/PavelEgorov-ru/crm-course/issues/new).

## Материалы на GitHub

Тексты, примеры и исходный код сайта находятся в [репозитории PavelEgorov-ru/crm-course](https://github.com/PavelEgorov-ru/crm-course). Там можно посмотреть изменения и предложить правку.
