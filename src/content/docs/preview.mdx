Эта страница показывает, как будут выглядеть материалы. Здесь можно оценить чтение, навигацию и интерактивные примеры. Это образец интерфейса; программа и статьи курса ещё в работе.

## Текст, которому хватает места

У каждого материала будет собственная ссылка. Заголовки собираются в оглавление, а нужный фрагмент можно найти через поиск. На небольшом экране навигация складывается в меню.

Внутри текста доступны **выделения**, списки, таблицы и ссылки. Например, можно [прочитать о проекте](../about/) или перейти к примеру ниже.

<Aside type="note" title="Короткое пояснение рядом с текстом">
  Такие блоки пригодятся для определений, важных деталей и подсказок. Их можно читать по ходу статьи и быстро находить при повторном просмотре.
</Aside>

## Код и дополнительные детали

Фрагменты кода можно скопировать одной кнопкой. Вкладки позволяют показать несколько представлений одного примера.

<Tabs>
  <TabItem label="Пример данных">

```json title="example.json"
{
  "name": "Анна",
  "channel": "email"
}
```

  </TabItem>
  <TabItem label="Пояснение">
    Это демонстрационные данные. В будущих материалах рядом с кодом появятся объяснения и задания, когда мы определимся с содержанием.
  </TabItem>
</Tabs>

<details>
  <summary>Так может выглядеть раскрывающаяся подсказка</summary>
  Дополнительные пояснения можно открывать по желанию — они не мешают основному тексту.
</details>
