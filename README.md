## Локальная работа

Нужна поддерживаемая версия Node.js (для проекта используется Node 24) и npm.

```sh
npm ci
npm run dev -- --background
```

Адрес разработки: `http://localhost:4321/crm-course/`.
Остановить фоновый сервер: `npm run astro -- dev stop`.

```sh
npm run build
npm run preview
```

`build` собирает сайт и поисковый индекс в `dist/`.
`preview` позволяет проверить именно собранный сайт, включая поиск.

## Материалы

- `src/content/docs/` — страницы Markdown и MDX.
- `src/components/` — интерактивные демонстрации.
- `src/styles/custom.css` — палитра и небольшие изменения оформления.
- `astro.config.mjs` — навигация, язык и адрес сайта.

Новая статья — файл `.md` или `.mdx` в `src/content/docs/` с полями `title` и `description` в начале. Добавьте её в `sidebar` в `astro.config.mjs`. Соблюдайте префикс `/crm-course/` у абсолютных внутренних ссылок; относительные ссылки тоже поддерживаются.

## Публикация

Изменения в `main` запускают `.github/workflows/deploy.yml`: сайт собирается и публикуется через GitHub Pages.
Проверяйте локальную сборку до отправки изменений. Черновики, не предназначенные для публикации, держите в отдельных ветках.

Все действия с GitHub для этого проекта выполняются от `PavelEgorov-ru`. Авторизация другого аккаунта, используемого для остальных проектов на компьютере, не должна переключаться глобально.
