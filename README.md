Пока опубликованы основа сайта и образец оформления; учебные статьи ещё не написаны.

## Локальная работа

Нужна поддерживаемая версия Node.js (для проекта используется Node 24) и npm.

```sh
npm ci
npm run dev -- --background
```

Адрес разработки: `http://localhost:4321/crm-course/`.
Остановить фоновый сервер: `npm run astro -- dev stop`.

```sh
npm run build
npm run preview
```

`build` собирает сайт и поисковый индекс в `dist/`.
`preview` позволяет проверить именно собранный сайт, включая поиск.

## Материалы

- Визуальный редактор: https://app.pagescms.org/ — войдите через личный GitHub `PavelEgorov-ru`, разрешите Pages CMS доступ только к `crm-course` и выберите этот репозиторий и ветку `main`.
- В разделе «Статьи» можно создавать материалы, оформлять текст и вставлять загруженные картинки. Раздел «О проекте» позволяет редактировать существующую страницу. Код и Markdown для этого не нужны.
- Сохранение в `main` запускает публикацию. В этой конфигурации сохранение не является приватным черновиком: материалы появятся на открытом сайте после успешной сборки.
- Настройка редактора хранится в `.pages.yml`. Для активации нужен однократный вход владельца и установка GitHub App Pages CMS.

- `src/content/docs/` — страницы Markdown и MDX.
- `src/content/docs/articles/` — статьи из визуального редактора; автоматически попадают в меню «Статьи».
- `public/images/` — загруженные картинки; публичные ссылки начинаются с `/crm-course/images/`.
- `src/components/` — интерактивные демонстрации.
- `src/styles/custom.css` — палитра и небольшие изменения оформления.
- `astro.config.mjs` — навигация, язык и адрес сайта.

Обычная статья — файл `.md` в `src/content/docs/articles/` с заголовком `title` и необязательным описанием `description` в начале. Редактор создаёт эти файлы сам. Положение в меню задаётся полем «Порядок» (`sidebar.order`); без него используется стандартная сортировка Starlight.

Главная и демостраница используют MDX-компоненты и пока редактируются через код: они не включены в визуальный редактор. Соблюдайте префикс `/crm-course/` у абсолютных внутренних ссылок; относительные ссылки тоже поддерживаются.

## Публикация

Изменения в `main` запускают `.github/workflows/deploy.yml`: сайт собирается и публикуется через GitHub Pages.
Проверяйте локальную сборку до отправки изменений. Черновики, не предназначенные для публикации, держите в отдельных ветках.

Все действия с GitHub для этого проекта выполняются от `PavelEgorov-ru`. Авторизация другого аккаунта, используемого для остальных проектов на компьютере, не должна переключаться глобально.
